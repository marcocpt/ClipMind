## 2. 已确认决策

### F1.14-D01：自动分类标签的管理边界

- 自动分类标签可由用户按单条剪贴项移除或恢复。
- 每条剪贴项只能恢复与自身分类结果对应的自动分类标签。
- 设置页只允许全局重命名或删除用户自定义标签。
- 自动分类标签在设置页可见但只读。

该决策已由用户在 Requirements 审核期间确认，并作为后续修订的固定边界。
