## 1. Background（背景）

ClipMind 已交付初赛 MVP（F1.1~F1.7）与 F1.9 快捷粘贴面板：剪贴板监听与捕获、自动分类、语义搜索、一键处理、本地加密存储、隐私保护、菜单栏常驻 + 主窗口交互，以及通过全局快捷键呼出独立快速粘贴面板完成"复制—呼出—粘贴"闭环。

F1.9 在交付时沿用历史默认全局快捷键 Cmd+Shift+V，触发的行为从"唤起主窗口"改为"呼出快速粘贴面板"，但快捷键本身未调整。该默认值在 F1.9 上线后的实际使用与市场调研反馈中暴露出冲突问题：Cmd+Shift+V 与 Paste、Paste、Maccy 等主流剪贴板工具的默认或常见快捷键发生冲突，部分市场调研报告明确指出该组合"会让人抓狂（this will drive you insane）"。新用户安装 ClipMind 后，系统快捷键被劫持，原有剪贴板工具失灵，影响首启体验与留存。

F1.10 的目标是将默认全局快捷键从 Cmd+Shift+V 修改为 Cmd+Shift+Space，避开主流剪贴板工具的冲突区，同时为已注册的老用户执行无感迁移，并扩展快捷键格式化工具对空格键的支持（解析、反向构造、显示）。

本特性不引入新的快捷键功能、不修改快捷键配置 UI、不改变 F1.9 触发行为（仍是呼出快速粘贴面板）。本特性属于"配置默认值修改 + 解析器扩展 + 老用户迁移"的局部增强，不引入新的数据模型或持久化方案。

## 2. Problem Statement（问题定义）

**核心问题**：当前默认全局快捷键 Cmd+Shift+V 与主流剪贴板工具冲突，导致：

1. **新用户首启被劫持**：新用户安装 ClipMind 后，系统注册 Cmd+Shift+V，若用户同时使用 Paste、Paste、Maccy 等工具，原工具的 Cmd+Shift+V 失灵，用户体验割裂。
2. **市场反馈负面**：市场调研报告明确指出 Cmd+Shift+V 是"会让人抓狂"的冲突选择，影响产品口碑与推荐意愿。
3. **快捷键格式化工具不支持空格键**：现有快捷键格式化工具仅支持字母键、数字键、功能键等，未支持空格键的解析、反向构造与显示。若直接将默认值改为 Cmd+Shift+Space，设置页快捷键录制器将无法正确显示与重新录制空格键组合。
4. **默认值散落多处**：当前默认快捷键字面值在应用设置、通用设置视图、快捷键录制器重置按钮三处独立硬编码，未来再次修改默认值需要多处同步修改，存在漂移风险。
5. **老用户无感迁移缺失**：现有版本没有"老用户旧默认值自动迁移"机制。若直接修改默认值，老用户升级后仍保留 Cmd+Shift+V，无法享受到避开冲突的新默认值；若强制覆盖，则会破坏用户已自定义的快捷键。

**影响用户**：

- 新用户：首启即遭遇快捷键冲突，影响首启体验与留存。
- 老用户（使用旧默认值）：升级后仍受冲突困扰，无法享受避坑默认值。
- 老用户（已自定义快捷键）：升级后保留自定义值，不受影响。

**不解决会怎样**：ClipMind 的"快速复用"价值（F1.9 交付）在冲突场景下被打折；市场口碑因快捷键冲突受损；后续若再次调整默认值，散落多处的硬编码会引入漂移缺陷。

## 3. Goals（目标）

### 3.1 用户目标

- 新用户首启后，默认快捷键为 Cmd+Shift+Space，按下后呼出快速粘贴面板。
- 老用户升级后，若曾使用旧默认值 Cmd+Shift+V，自动迁移到 Cmd+Shift+Space，无需手动配置。
- 老用户升级后，若已自定义快捷键（非 Cmd+Shift+V），保留不变。
- 设置页快捷键录制器默认显示 ⌘⇧Space，重置按钮点击后回到 Cmd+Shift+Space。

### 3.2 业务目标

- 把 ClipMind 的默认快捷键从冲突区移出，避开 Paste、Paste、Maccy 等主流剪贴板工具的常见组合。
- 为后续再次调整默认值建立"测试常量集"基础设施：默认值、历史默认值、任意有效值在测试中以常量引用，后续修改默认值时只改一处。
- 保持 App Store 合规：本特性仅修改默认值与扩展解析器，不改变全局快捷键的注册流程与权限模型，主 Scheme ClipMind 仍完全合规。

### 3.3 成功标准

- 新安装用户默认快捷键为 Cmd+Shift+Space，触发呼出快速粘贴面板。
- 老用户升级后，旧默认值 Cmd+Shift+V 自动迁移到 Cmd+Shift+Space，自定义值保留不变。
- 快捷键格式化工具支持空格键的解析、反向构造与显示。
- 设置页快捷键录制器默认显示 ⌘⇧Space，重置按钮重置到新默认值。
- 测试常量集抽取完成，后续修改默认值时只改一处。
- 10 条 AC 全部通过（XCTest + XCUITest + 手动验收）。

## 4. Scope（范围）

### 4.1 必须做

- 扩展快捷键格式化工具，支持空格键的解析、反向构造与显示（用户可见的显示形式为 ⌘⇧Space 大写形式）。
- 修改默认全局快捷键字面值，从旧默认值改为新默认值（Cmd+Shift+Space），并保持应用设置、通用设置视图、快捷键录制器重置按钮三处默认值同步。
- 实现老用户无感迁移：升级时检测旧默认值并自动迁移为新默认值；自定义值保留不变。
- 抽取测试常量集（包含当前默认值、历史默认值、任意有效值三个常量），让后续默认值修改只需调整一处。
- 测试调整：修改默认值断言、保留旧默认值解析器测试作为回归保护、新增针对本特性的专项测试。
- 同步更新 F1 主设计规范、F1.9 测试用例表与视觉原型中涉及默认快捷键字面值的位置。
- 编写 F1.10 规格文档套件（需求文档、设计文档、视觉原型、测试用例表）。

## 5. Functional Requirements（功能需求）

### FR-001：默认全局快捷键改为 Cmd+Shift+Space

**需求**：新安装用户首次启动后，默认全局快捷键为 Cmd+Shift+Space，触发行为沿用 F1.9（呼出快速粘贴面板，不唤起主窗口）。

**行为**：

- 应用首次启动且用户未配置过快捷键时，持久化的默认快捷键值为新默认值。
- 默认值在应用设置、通用设置视图的应用存储、快捷键录制器重置按钮三处保持字面一致。
- 触发行为不变：按下快捷键发送"打开快速粘贴面板"信号，由应用主代理接收并调起 F1.9 的快速粘贴面板。
- 菜单栏图标的 toggle popover 行为不受影响。

### FR-002：快捷键格式化工具支持空格键解析

**需求**：快捷键格式化工具能将"命令+Shift+空格"的存储表示解析为对应的键码与修饰键组合。

**行为**：

- 输入新默认值的存储表示（含空格键标识），解析结果包含空格键的键码与命令、Shift 两个修饰键。
- 输入旧默认值的存储表示（含字母 V），解析结果包含字母 V 的键码与命令、Shift 两个修饰键（回归保护，行为不变）。
- 解析失败的输入（如未识别的键名）按现有失败路径处理，不引入新的异常。

### FR-003：快捷键格式化工具支持空格键反向构造

**需求**：快捷键格式化工具能从"命令+Shift 修饰键 + 空格键码"反向构造出存储表示，与解析路径互逆。

**行为**：

- 输入命令修饰键 + Shift 修饰键 + 空格键码，反向构造结果为新默认值的存储表示。
- 输入命令修饰键 + Shift 修饰键 + 字母 V 键码，反向构造结果为旧默认值的存储表示（回归保护，行为不变）。
- 反向构造与解析互逆：解析后再反向构造，结果与原输入一致。

### FR-004：快捷键格式化工具支持空格键显示

**需求**：快捷键格式化工具能将"命令+Shift+空格"的存储表示显示为用户可见的 ⌘⇧Space 大写形式，与现有字母键的大写显示风格一致。

**行为**：

- 输入新默认值的存储表示，显示结果为 ⌘⇧Space（命令符号 + Shift 符号 + 大写 Space 字样）。
- 输入旧默认值的存储表示，显示结果为 ⌘⇧V（行为不变，回归保护）。
- 显示形式与现有字母键、数字键、功能键的大写显示风格一致（首字母大写或全大写形式）。

### FR-005：老用户旧默认值自动迁移

**需求**：老用户升级到本版本后，若持久化的快捷键为旧默认值，自动迁移为新默认值，无需用户手动配置。

**行为**：

- 应用启动时执行一次迁移检查。
- 检测到持久化快捷键等于旧默认值（字面相等）时，将其更新为新默认值并持久化。
- 检测到持久化快捷键为其他值（用户自定义值、新默认值、空值）时，不修改。
- 迁移在应用设置初始化阶段完成，迁移完成后整个生命周期内不再重复迁移。
- 迁移过程不弹任何提示对话框，不打断用户首启流程。
- 迁移日志仅记录迁移事件元数据（如"已迁移旧默认快捷键"），不记录快捷键字面值。

### FR-006：老用户自定义值保留

**需求**：老用户升级到本版本后，若持久化的快捷键为用户自定义值（非旧默认值），保留不变。

**行为**：

- 应用启动时迁移检查发现快捷键不等于旧默认值，不修改。
- 用户自定义值可能是任意有效快捷键组合（如 Ctrl+Option+A、Cmd+Shift+1 等），均保留。
- 空值或无效值按现有失败路径处理，不强制覆盖为新默认值（避免覆盖用户主动清空的配置）。

### FR-007：快捷键录制器重置按钮重置为新默认值

**需求**：设置页快捷键录制器的"重置"按钮点击后，快捷键重置为新默认值。

**行为**：

- 用户点击重置按钮后，快捷键值变更为新默认值。
- 重置后的值立即持久化，下次启动时仍为新默认值。
- 重置操作触发的全局快捷键注册流程按现有路径执行（注销旧值、注册新值）。
- 重置后设置页快捷键录制器显示更新为新默认值的用户可见形式（⌘⇧Space）。

### FR-008：设置页快捷键录制器默认显示新默认值

**需求**：设置页快捷键录制器在用户未自定义快捷键时，默认显示新默认值的用户可见形式。

**行为**：

- 新用户首启后打开设置页，快捷键录制器显示 ⌘⇧Space。
- 老用户迁移后打开设置页，快捷键录制器显示 ⌘⇧Space（迁移后的新默认值）。
- 老用户保留自定义值时打开设置页，快捷键录制器显示自定义值的用户可见形式。
- 显示形式由快捷键格式化工具的显示方法生成，与本特性 FR-004 一致。

### FR-009：全局快捷键 Cmd+Shift+Space 可注册并触发快速粘贴面板

**需求**：新默认值 Cmd+Shift+Space 能被系统全局快捷键注册机制接受并注册成功，按下时触发 F1.9 的"打开快速粘贴面板"信号。

**行为**：

- 应用启动时按持久化快捷键值注册全局快捷键。
- 新默认值注册成功，无系统级冲突（与 Paste、Maccy 等主流剪贴板工具的常见组合不冲突）。
- 注册成功后按下 Cmd+Shift+Space，发送"打开快速粘贴面板"信号，由应用主代理接收并调起 F1.9 的快速粘贴面板。
- 注册失败的现有错误处理路径不变（如快捷键已被其他应用占用时按现有逻辑提示用户）。

### FR-010：测试常量集抽取

**需求**：抽取测试常量集，包含当前默认值、历史默认值、任意有效值三个常量，让后续再次修改默认值时只需调整一处。

**行为**：

- 测试常量集提供"当前默认值"常量，用于断言应用设置的默认值与设置页显示。
- 测试常量集提供"历史默认值"常量，用于回归保护测试（验证旧默认值仍可解析）。
- 测试常量集提供"任意有效值"常量，用于服务层 fixture 测试中非断言目标的快捷键值（提升语义）。
- 测试常量集位于测试目录下，仅测试代码引用，不污染生产代码。
- 后续再次修改默认值时，仅修改测试常量集中的"当前默认值"与"历史默认值"两个常量，所有引用处自动同步。

### FR-011：历史默认值解析回归保护

**需求**：本特性修改默认值后，旧默认值 Cmd+Shift+V 仍能被快捷键格式化工具正确解析、反向构造与显示，确保已持久化旧默认值的老用户在迁移前的解析路径正确。

**行为**：

- 旧默认值的存储表示仍可被解析为对应键码与修饰键组合。
- 旧默认值的键码与修饰键仍可被反向构造为存储表示。
- 旧默认值的存储表示仍可被显示为 ⌘⇧V 用户可见形式。
- 本特性不删除、不废弃旧默认值的解析路径，仅调整默认值字面值。

## 6. Non-functional Requirements（非功能需求）

### NFR-001：兼容性

- 兼容 macOS 13+（与项目基线一致，不使用 macOS 14+ 专有 API）。
- 兼容 Apple Silicon（arm64）与 Intel（x86_64）。
- 兼容现有快捷键注册机制（系统全局快捷键 API），不引入新的依赖或框架。
- 兼容 F1.9 的快捷键触发行为（呼出快速粘贴面板），不破坏 F1.9 已交付的流程。
- 兼容现有快捷键配置 UI（设置页快捷键录制器），不修改其交互。

### NFR-002：性能

- 老用户迁移检查在应用设置初始化阶段执行，耗时 ≤ 5ms（单次字符串比较 + 必要时一次持久化写入）。
- 新默认值的快捷键注册耗时与旧默认值一致（注册耗时与具体键码无关）。
- 快捷键格式化工具的解析、反向构造、显示方法对空格键的支持不引入可感延迟（< 1ms）。

### NFR-003：稳定性

- 老用户迁移在 100 次连续升级场景中无崩溃、无数据丢失、无快捷键失效。
- 迁移逻辑是幂等的：多次执行迁移检查不会产生副作用（已迁移的快捷键不再被修改）。
- 迁移失败时（如持久化写入失败），按现有错误处理路径记录日志，不影响应用启动。

### NFR-004：安全性

- 不在日志中输出快捷键字面值（避免泄露用户偏好与配置）。
- 迁移日志仅记录迁移事件元数据（如"已迁移旧默认快捷键"），不记录原值与新值。
- 快捷键格式化工具的解析、反向构造、显示方法不读取或输出剪贴板内容。

### NFR-005：合规性（App Store）

- 主 Scheme ClipMind 仍完全合规：启用 App Sandbox、仅申请最小必要 entitlement、不使用私有 API、不改变快捷键注册流程的权限模型。
- 本特性仅修改默认值字面值与扩展快捷键格式化工具的键名映射，不引入新的权限或 entitlement。
- 本特性不涉及敏感剪贴板内容的持久化（快捷键配置不属于敏感剪贴板内容）。
- 本特性不需要暂存到 ClipMind-Dev 开发验证 Scheme，可直接合入主 Scheme ClipMind。

### NFR-006：可维护性

- 默认快捷键字面值在应用代码中仅出现一处（应用设置层），通用设置视图与快捷键录制器重置按钮通过引用该处的常量或默认值获取。
- 测试常量集位于测试目录下，集中管理当前默认值、历史默认值、任意有效值三个常量。
- 后续再次修改默认值时，生产代码修改一处，测试代码修改一处（测试常量集），所有引用处自动同步。

## 7. Constraints（约束）

- **App Store 主 Scheme 合规**：所有面向发布的代码必须满足 App Store Review Guidelines 与 macOS 沙盒、隐私、权限约束。

- **不引入新的权限或 entitlement**：沿用现有快捷键注册所需的权限。

## 8. Acceptance Criteria（验收标准）

> **格式约定**：每条 AC 用 Given/When/Then 描述，验证方式必须包含测试框架（XCTest/XCUITest/手动）。
> **AC 编号体系**：AC-F1.10-1 ~ AC-F1.10-10（含 1 条回归保护 AC-F1.10-10），独立于 F1 主规范与 F1.9 的 AC 编号。

### AC-F1.10-1：快捷键格式化工具解析新默认值

- **Given** 快捷键格式化工具已初始化
- **When** 输入新默认值的存储表示（含空格键标识）
- **Then** 解析结果包含空格键的键码与命令、Shift 两个修饰键
- **验证方式**：XCTest 新增

### AC-F1.10-2：快捷键格式化工具显示新默认值为大写形式

- **Given** 快捷键格式化工具已初始化
- **When** 输入新默认值的存储表示
- **Then** 显示结果为 ⌘⇧Space（命令符号 + Shift 符号 + 大写 Space 字样），与字母键的大写显示风格一致
- **验证方式**：XCTest 新增

### AC-F1.10-3：快捷键格式化工具反向构造新默认值

- **Given** 快捷键格式化工具已初始化
- **When** 输入命令修饰键 + Shift 修饰键 + 空格键码
- **Then** 反向构造结果为新默认值的存储表示，与 AC-F1.10-1 的输入一致（解析与反向构造互逆）
- **验证方式**：XCTest 新增

### AC-F1.10-4：应用设置默认快捷键为新默认值

- **Given** 应用首次启动，用户未配置过快捷键
- **When** 应用设置初始化完成
- **Then** 应用设置的快捷键默认值为新默认值（Cmd+Shift+Space）
- **验证方式**：XCTest 修改现有默认值断言

### AC-F1.10-5：老用户旧默认值自动迁移

- **Given** 老用户持久化的快捷键为旧默认值（Cmd+Shift+V）
- **When** 应用启动并执行迁移检查
- **Then** 持久化的快捷键被更新为新默认值（Cmd+Shift+Space），下次启动时仍为新默认值
- **验证方式**：XCTest 新增

### AC-F1.10-6：老用户自定义值保留不变

- **Given** 老用户持久化的快捷键为自定义值（非旧默认值，如 Ctrl+Option+A）
- **When** 应用启动并执行迁移检查
- **Then** 持久化的快捷键保持不变，不被覆盖
- **验证方式**：XCTest 新增

### AC-F1.10-7：快捷键录制器重置按钮重置为新默认值

- **Given** 设置页快捷键录制器已显示，当前快捷键为任意值
- **When** 用户点击重置按钮
- **Then** 快捷键值变更为新默认值（Cmd+Shift+Space），立即持久化，设置页显示更新为 ⌘⇧Space
- **验证方式**：XCTest 新增

### AC-F1.10-8：全局快捷键新默认值可注册并触发快速粘贴面板

- **Given** 应用已启动，快捷键已注册为新默认值（Cmd+Shift+Space）
- **When** 用户在任意应用中按下 Cmd+Shift+Space
- **Then** 快捷键注册成功，触发"打开快速粘贴面板"信号，快速粘贴面板窗口出现
- **验证方式**：XCTest 新增 + 手动验收

### AC-F1.10-9：设置页快捷键录制器默认显示新默认值

- **Given** 新用户首启后打开设置页（或老用户迁移后打开设置页）
- **When** 快捷键录制器加载完成
- **Then** 快捷键录制器显示 ⌘⇧Space（新默认值的用户可见形式）
- **验证方式**：XCUITest 新增

### AC-F1.10-10（回归保护）：快捷键格式化工具仍可解析旧默认值

- **Given** 快捷键格式化工具已初始化
- **When** 输入旧默认值的存储表示（Cmd+Shift+V）
- **Then** 解析结果包含字母 V 的键码与命令、Shift 两个修饰键（行为与修改默认值前一致）
- **验证方式**：XCTest 保留现有用例（回归保护）

## 11. Decision Freedom（实现自由度）

### 11.1 允许的实现自由度

- **空格键的键名标识选择**：在快捷键格式化工具的键名映射中，空格键的标识可以是 "space"、"Space"、"SPACE" 或其他大小写形式的任意一种，只要满足"解析、反向构造、显示互逆"约束。具体形式由实现方决定，但需在测试常量集中保持一致。
- **空格键显示形式的具体写法**：显示方法对空格键的呈现可以是 "Space"、"SPACE"、"空格" 等形式中的任意一种，只要满足"与字母键大写显示风格一致"约束。本特性推荐 "Space"（首字母大写，与字母键一致），但实现方可选择其他形式并在测试中固定。
- **测试常量集的实现形式**：可以是枚举、结构体、命名空间常量的任意一种，只要满足"集中管理、测试代码引用、不污染生产代码"约束。
- **迁移方法的命名**：老用户迁移方法的命名由实现方决定，只要在应用设置初始化阶段被调用且行为符合 FR-005。
- **迁移检查的实现方式**：可以是字符串相等比较、模式匹配、键值查找等任意一种，只要满足"仅当快捷键等于旧默认值时迁移"约束。
- **默认值常量的实现形式**：生产代码中的默认快捷键常量可以是字符串字面值、命名常量、配置枚举的任意一种，只要满足"应用代码中仅出现一处"约束。
- **设置页显示更新方式**：设置页快捷键录制器的显示更新可以是绑定触发、显式刷新、观察者模式的任意一种，只要满足"快捷键值变更后显示立即同步"约束。

### 11.2 禁止的实现方式

- **禁止在多处硬编码默认值**：默认快捷键字面值不得在应用设置、通用设置视图、快捷键录制器重置按钮三处独立硬编码，必须通过引用同一处常量或默认值获取。
- **禁止迁移逻辑覆盖自定义值**：迁移检查仅当快捷键等于旧默认值时迁移，禁止覆盖用户自定义值、空值、无效值。
- **禁止迁移逻辑弹出提示对话框**：迁移过程不得弹任何提示、确认、警告对话框，不打断用户首启流程。
- **禁止在日志中输出快捷键字面值**：迁移日志与快捷键格式化工具的日志仅记录事件元数据（如"已迁移旧默认快捷键"），不记录快捷键字面值。
- **禁止删除旧默认值的解析路径**：旧默认值 Cmd+Shift+V 的键名映射不得删除，确保已持久化旧值的老用户在迁移前的解析路径正确（回归保护）。
- **禁止使用私有 API 或绕过沙盒**：所有实现必须使用公开 API，满足 App Store 合规。
- **禁止修改快捷键注册机制**：不引入新的快捷键注册路径，沿用现有系统全局快捷键 API。
- **禁止修改 F1.9 的触发行为**：快捷键按下后仍发送"打开快速粘贴面板"信号，不修改 F1.9 的快速粘贴面板控制器、视图、粘贴流程协调器等模块。
- **禁止修改快捷键配置 UI**：保留现有设置页快捷键录制器的交互、视觉、配置能力。
- **禁止用固定 sleep 等待异步逻辑**：迁移检查与持久化写入不得用固定 sleep 掩盖竞态，使用明确的条件等待或同步路径。
- **禁止测试常量集污染生产代码**：测试常量集位于测试目录下，仅测试代码引用，不得被生产代码引用。
- **禁止引入第三方快捷键管理库**：不引入新的依赖或框架，沿用现有快捷键格式化工具与注册机制。

## 12. Future Considerations（未来扩展）

### 12.1 快捷键冲突检测

- 当前不做快捷键冲突检测，未来可在设置页快捷键录制器中增加"冲突检测"功能，提示用户当前快捷键是否与系统或其他应用冲突。
- 需考虑系统全局快捷键 API 的查询能力（部分系统不提供"查询某快捷键是否已被占用"的公开 API）。

### 12.2 快捷键方案

- 当前仅支持单一全局快捷键，未来可扩展"快捷键方案"（如"快速粘贴方案"、"打开主窗口方案"），允许用户配置多个独立快捷键。
- 需考虑快捷键管理与冲突避免。

### 12.3 二次快捷键 toggle 关闭

- 当前快捷键是单向触发（按一次呼出快速粘贴面板），关闭通过 Esc/失焦/粘贴完成。
- 未来可扩展"再按一次关闭面板"的 toggle 模式。
- 需解决快捷键在面板已打开时被前台应用拦截的状态一致性问题（与 F1.9 12.3 一致）。

### 12.4 快捷键使用统计

- 当前不记录快捷键使用次数，未来可扩展"快捷键使用次数"统计字段，用于排序或推荐。
- 需考虑隐私：使用次数是元数据，不涉及剪贴板原文，可安全存储。

### 12.5 自定义快捷键导入导出

- 当前不支持快捷键配置导入导出，未来可扩展为用户在多设备间同步快捷键配置。
- 需考虑配置格式兼容性（不同版本的存储表示可能不同）。

### 12.6 多显示器下快捷键注册

- 当前快捷键在所有显示器生效，未来可考虑多显示器场景下的注册范围（如仅在主显示器注册）。
- 需考虑系统 API 支持情况。

### 12.7 快捷键录制器的录制反馈

- 当前快捷键录制器的录制流程不变，未来可扩展更丰富的录制反馈（如按键可视化、冲突提示、组合合法性检查）。
- 需考虑与现有录制器的兼容性。
