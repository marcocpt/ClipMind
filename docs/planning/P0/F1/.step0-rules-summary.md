## 0.4 项目编码规范关键点（影响设计文档）

来自 `docs/CODING_STANDARDS.md`：

- Swift 5.7+ / macOS 13.0+
- Allman 大括号、4 空格缩进
- 模块组织：`App`、`Capture`、`Classify`、`LLM`、`ML`、`Models`、`Privacy`、`Search`、`Storage`、`UI`、`Utils`
- 依赖方向：UI → 业务模块 → Models / Utils，不反向
- 外部依赖通过 SQLite.swift（SPM）
- 初始化依赖注入
- UI 状态必须 @MainActor 隔离
- 禁止 print()，使用 LogCategory
- 禁止魔术数字/魔术字符串
- 禁止用 sleep 等待异步逻辑
- 禁止吞掉错误
- 测试只 mock 外部依赖，不 mock 被测对象本身

## 0.5 Git 提交规范
