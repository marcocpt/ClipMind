## 关键设计决策

### 1. 视图层合并

- 菜单栏弹窗视图与快捷粘贴面板视图合并为统一粘贴面板视图
- 由状态栏图标控制器（菜单栏弹窗场景）和快捷键面板控制器（快捷键场景）分别包装
- 底部工具栏条件渲染：菜单栏弹窗场景显示三按钮，快捷键场景隐藏
- 收益：列表渲染、键盘事件、选中态逻辑只在一处实现，降低后续迭代成本

### 2. 面板关闭协议扩展

- 状态栏图标控制器新增实现面板关闭协议
- 关闭菜单栏弹窗与关闭快捷键面板使用统一接口
- 粘贴协调器通过协议接口同时支持两个场景
- 收益：粘贴流程编排与具体面板类型解耦

### 3. 数据源统一

- 剪贴项列表由外部注入，视图不直接读取剪贴板存储
- 状态栏图标控制器与快捷键面板控制器从同一剪贴板存储取数据
- 收益：视图与持久化解耦，依赖方向保持 UI → 业务模块 → 数据模型层

### 4. 合规风险标注

- 无权限降级方案（FR-011）纯沙盒内实现，App Store 完全合规
- 有权限方案（FR-010）使用公开 API + 标准 TCC 权限流程，合规风险在设计文档第 10 节独立标注「合规待定」
- 若 App Store 审核拒绝有权限方案，则该方案暂存到开发验证 Scheme，主方案仅保留无权限降级方案
