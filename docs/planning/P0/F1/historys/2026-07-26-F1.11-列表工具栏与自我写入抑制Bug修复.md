# F1.11 列表工具栏与自我写入抑制 Bug 修复

> 最后更新：2026-07-26 | 版本：v1.0

## 变更摘要

本次提交修复 F1.11 菜单栏弹窗双击粘贴功能的 3 个 Bug：

- **Bug 1（主窗口列表点击无响应）**：主窗口剪贴项列表点击无响应，详情面板未更新。修复 `HistoryListView` 的事件处理，新增 `MainWindowUITests.testMainWindowListClick_UpdatesDetailPanel` 回归测试。
- **Bug 2（全局热键面板底部工具栏缺失与图标化）**：快捷键场景（`QuickPasteAssembly`）补齐底部工具栏（`showsBottomBar: true`），与菜单栏弹窗场景对齐；底部工具栏按钮由文字改为 SF Symbol 图标（`list.bullet` / `gearshape` / `power`），保留中文 `accessibilityLabel`。
- **Bug 3（双击粘贴后列表重复）**：`ClipboardWriter` 新增 `suppressor: SelfWriteSuppressor?` 入参（默认 `nil` 保持向后兼容），写入成功后调用 `markSelfWrite(changeCount:)` 标记自我写入，`PasteboardWatcher` 跳过本次捕获避免列表重复。3 处 `PasteCoordinator` 装配点注入共享 `SelfWriteSuppressor` 实例，与 F2.1 `ClipboardReplacer` 共用同一套抑制机制。

## 关键设计决策

### 1. Bug 2 reversal F1.11 设计文档 7.3 决策

F1.11 设计文档 v1.0 第 7.3 节原决策「底部工具栏通过外部参数控制显隐而非运行时切换」假设「两场景视觉差异」（菜单栏弹窗场景显示三按钮，快捷键场景隐藏）。Bug 2 修复后该假设被推翻：快捷键场景也显示底部工具栏（`showsBottomBar: true`），与菜单栏弹窗场景对齐。外部参数注入机制保留（可用于未来扩展），但当前两个装配点（`QuickPasteAssembly` / `StatusItemAssembly`）均传 `true`。「退出」按钮在快捷键场景也调用 `onExitApp` 退出应用。

### 2. Bug 2 按钮形态从文字改为 SF Symbol 图标

底部工具栏三按钮由文字（「查看全部」/「配置」/「退出」）改为 SF Symbol 图标常量：

- 「查看全部」→ `list.bullet`
- 「配置」→ `gearshape`
- 「退出」→ `power`

图标常量在 `BottomToolbarView` 中以命名常量暴露（`viewAllIconName` / `settingsIconName` / `exitIconName`），便于单元测试验证。辅助功能标签保留中文文案（`accessibilityLabel`），满足 NFR-005 可访问性。

### 3. Bug 3 ClipboardWriter 注入 SelfWriteSuppressor

`ClipboardWriter` 的 `init` 新增 `suppressor: SelfWriteSuppressor? = nil` 入参（默认 `nil` 保持向后兼容）：

- 写入剪贴板成功后，若 `suppressor` 非 `nil`，调用 `suppressor.markSelfWrite(changeCount:)` 标记本次写入为「自我写入」。
- `PasteboardWatcher` 在捕获剪贴板变化时查询 `SelfWriteSuppressor`，若变化计数与最近一次自我写入匹配则跳过本次捕获，避免应用自身写入被误识别为「用户外部新复制」导致列表重复。
- 与 F2.1 `ClipboardReplacer` 共用同一套抑制机制（共享 `SelfWriteSuppressor` 实例），确保两条路径行为一致。
- 3 处 `PasteCoordinator` 装配点（`QuickPasteAssembly` / `StatusItemAssembly` / `PopoverPreviewWindowFactory`）注入同一个共享 suppressor 实例，确保两场景（快捷键 / 菜单栏弹窗）行为一致。

## 影响的 AC

- **AC-F1.11-8**（「退出」按钮退出整个应用）：Bug 2 修复后，快捷键场景的「退出」按钮也调用 `onExitApp` 退出应用（原仅菜单栏弹窗场景生效）。
- **AC-F1.11-13**（底部工具栏条件渲染）：Bug 2 修复后，两场景（菜单栏弹窗 / 快捷键）均显示底部工具栏，原「快捷键场景隐藏」假设被 reversal。
