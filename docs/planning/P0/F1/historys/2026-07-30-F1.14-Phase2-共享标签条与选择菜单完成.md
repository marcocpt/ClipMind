## 关键实现回顾

Phase 2 实现过程中关键决策与修复（详见提交历史）：

1. **共享 TagStore**：在 `AppDelegate` 持有唯一 `TagStore` 实例，注入到主窗口、菜单栏弹窗、快捷粘贴面板三个入口。
2. **TagPickerPresenter**：因 SwiftUI `.popover()` 在手动 NSWindow 上下文中不稳定，改用 NSPanel 承载标签选择菜单，并通过 `NonHitTestView` 锚点解决点击拦截。
3. **ClipRowView 事件隔离**：将 `onTapGesture` 从内层 VStack 移到外层 VStack，让标签 pill 的 `Button` 优先级高于行级 tap，避免事件传播。
4. **HistoryListView 改造**：从 `List` 切换为 `ScrollView + LazyVStack`，避免 List 拦截子视图 Button 的 tap gesture；通过 `ScrollView` 的 `accessibilityValue` 暴露 `filteredClips.count` 给 UI 测试。
5. **testPanelCloses_OnResignFocus 修复**：因 SwiftUI WindowGroup 创建的主窗口在 CI 中不可靠可见，新增 `--UITEST_TRIGGER_PANEL_RESIGN` 启动参数，3 秒后创建临时 NSWindow 抢夺 key 状态，可靠触发面板 `didResignKey` → `closePanelInternal`。
6. **三入口 UI 测试夹具**：通过 `--UITEST_TAG_FIXTURE`、`--UITEST_TAG_LIMIT_FIXTURE`、`--UITEST_TAG_EMPTY_CLIP` 注入稳定数据；`CLIPMIND_DEV` 编译条件保证夹具不进入生产构建。
