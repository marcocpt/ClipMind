# F1.11 Bug 4 双击粘贴后置顶被粘贴项

> 最后更新：2026-07-26 | 版本：v1.0

## 变更摘要

本次提交修复 F1.11 菜单栏弹窗双击粘贴功能的 Bug 4：双击粘贴后被粘贴项未移到列表最前面，导致用户下次打开面板时仍需滚动查找刚粘贴的内容。

修复方案：新增 `EncryptedStore.touchTimestamp(id:to:)` 更新指定 ClipItem 的 timestamp，`PasteCoordinator` 在剪贴板写入成功后调用 `clipToucher.touch(id:)` 把被粘贴项移到列表最前面（按 `timestamp DESC` 排序）。

## 关键设计决策

### 1. ClipItem.timestamp 改为 var

`ClipItem.timestamp` 原为 `let` 不可变。Bug 4 需要 `loadAll()` 在反序列化后用数据库列的当前值覆盖 JSON 里的旧值（确保 `touchTimestamp` 更新生效），因此改为 `var`。

仅 `timestamp` 字段改为 `var`，其他字段（`id` / `content` / `contentType` / `sourceApp` / `sourceAppName` / `summary` / `translation` / `rewrite` / `todos` / `embeddings`）保持 `let`，不破坏不可变性约束。

### 2. loadAll 用数据库 timestamp 列覆盖反序列化值

`EncryptedStore.loadAll()` 原仅读取 `contentBlob`（加密 JSON）并反序列化。Bug 4 修改为同时读取 `timestampColumn`，反序列化后用数据库列的当前值覆盖 `item.timestamp`。

原因：`touchTimestamp` 只更新数据库列，不重新加密整个 ClipItem JSON。如果 `loadAll` 仍用 JSON 里的旧 timestamp，排序会不一致。覆盖后确保列表排序（`timestamp DESC`）与显示时间都反映 `touchTimestamp` 的更新。

### 3. ClipTouching 协议 + EncryptedStoreClipToucher 实现

新增 `ClipTouching` 协议（`func touch(id: UUID) -> Bool`）抽象「置顶被粘贴项」行为，`EncryptedStoreClipToucher` 是生产实现（内部调用 `EncryptedStore.touchTimestamp`）。

`PasteCoordinator` 通过 `clipToucher: ClipTouching?` 入参注入（默认 `nil` 保持向后兼容）。3 处装配点（`QuickPasteAssembly` / `StatusItemAssembly` / `PopoverPreviewWindowFactory`）注入同一个共享 `clipToucher` 实例，与共享 `selfWriteSuppressor` 一致，确保两场景（快捷键 / 菜单栏弹窗）行为一致。

### 4. 写入失败时不调用 clipToucher

`PasteCoordinator.handlePaste` 在 `clipboardWriter.write(text:)` 返回 `false` 时通过 `guard writeSuccess else { return }` 提前返回，不调用 `clipToucher.touch(id:)`。

原因：写入失败时剪贴板内容未更新，被粘贴项的 timestamp 不应被更新（避免无效置顶把失败项移到列表前面误导用户）。

### 5. 抽取 PasteCoordinatorMocks.swift 缓解 file_length

`PasteCoordinatorTests.swift` 原 620 行（含 Bug 4 新增测试 + Mock 类），超过 SwiftLint `file_length` 500 行限制。抽取所有 Mock 类（`MockPermissionChecker` / `MockClipboardWriter` / `MockClipToucher` / `MockPanelCloser` / `MockOverlayShower` / `MockPasteSimulator` / `ScreenCenterLocatorForIntegration`）和共享 `sharedCallSequence` 计数器到独立的 `PasteCoordinatorMocks.swift`（149 行），主测试文件降至 428 行。

Mock 类由 `private` 改为 `internal`（默认访问级别），跨文件可见。`sharedCallSequence` 同样改为 `internal`，供 `PasteCoordinatorTests.setUp()` 重置。

## 影响的 AC

- **AC-F1.11-3**（双击剪贴项粘贴到前台应用）：Bug 4 修复后，双击粘贴成功后被粘贴项移到列表最前面，下次打开面板时用户能立即看到最近粘贴的内容。
- **AC-F1.11-4**（回车键粘贴选中项）：同上，回车粘贴后也触发置顶。
