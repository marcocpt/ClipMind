## 1. Background（背景）

ClipMind 已交付初赛 MVP（F1.1~F1.7）和 F1.9 快捷粘贴面板：

- F1.1~F1.7 完成剪贴板监听与捕获、自动分类、语义搜索、一键处理、本地加密存储、隐私保护、菜单栏常驻 + 主窗口交互。
- F1.9 新增「快捷粘贴面板」入口：用户在任意应用准备粘贴时，按全局快捷键直接在粘贴目标附近呼出独立面板，单击高亮、双击粘贴、键盘导航、失焦关闭、无权限降级浮层。

但是，**菜单栏点击入口的弹窗（菜单栏弹窗）和快捷粘贴面板是两个交互割裂的入口**：

- 菜单栏弹窗仅展示历史剪贴项列表，**不支持双击粘贴、回车粘贴、方向键导航、Esc 关闭**，列表行无任何交互（仅展示）。
- 用户通过菜单栏图标点击进入后，若想粘贴某条历史内容到当前应用，必须：移动鼠标到菜单栏 → 点击图标 → 在弹窗中找到条目 → 切换回目标应用 → 手动按系统粘贴键。至少 4 步操作 + 2 次应用切换，破坏「复制—粘贴」肌肉记忆。
- 菜单栏弹窗底部仅有「查看全部」一个按钮，缺少「打开设置」「退出」等便捷入口，用户必须先关闭弹窗再走其他路径。
- 菜单栏弹窗视图与快捷粘贴面板视图是两套独立实现，存在大量重复代码（列表行渲染、键盘事件、选中态等），后续维护与扩展需要双倍成本。

F1.11 的目标是把菜单栏弹窗与快捷粘贴面板的交互完全对齐：菜单栏弹窗支持与快捷粘贴面板完全一致的双击粘贴/键盘导航/选中态/默认高亮第一行/Esc 关闭；同时合并两个入口的视图层，使列表渲染、键盘交互、选中态逻辑只在一处实现；并新增底部工具栏「查看全部/配置/退出」三按钮，把菜单栏弹窗升级为完整的剪贴复用入口。

本特性沿用 F1.9 已建立的粘贴协调器、系统粘贴权限检查器、剪贴板写入器、粘贴浮层控制器等基础设施，不引入新的权限申请流程，不修改剪贴板存储的持久化逻辑。

## 2. Problem Statement（问题定义）

**核心问题**：菜单栏弹窗与快捷粘贴面板是两个交互割裂的入口，导致以下可验证问题：

1. **菜单栏弹窗不支持双击粘贴**：菜单栏弹窗中的列表行无任何点击/键盘交互，用户在菜单栏弹窗中选中条目后无法直接触发粘贴，必须手动切换回目标应用并按系统粘贴键。可验证：菜单栏弹窗打开后，双击任意文本行，无任何粘贴相关行为发生。
2. **菜单栏弹窗不支持键盘导航**：菜单栏弹窗不支持方向键移动选中、回车粘贴、Esc 关闭，全靠鼠标操作。可验证：菜单栏弹窗打开后按方向键/回车/Esc，无任何响应。
3. **菜单栏弹窗无默认高亮**：菜单栏弹窗打开后，列表无默认选中行，用户必须先用鼠标点击某行才能开始交互。可验证：菜单栏弹窗打开后，列表第一行无高亮显示。
4. **菜单栏弹窗底部工具单一**：菜单栏弹窗底部仅有「查看全部」一个按钮，缺少「打开设置」「退出」入口，用户必须先关闭弹窗才能进入设置或退出应用。可验证：菜单栏弹窗底部按钮区域只有一个按钮。
5. **两套视图代码重复**：菜单栏弹窗视图与快捷粘贴面板视图各自维护列表渲染、行视图、选中态、键盘事件逻辑，后续修改需要双倍成本。可验证：当前两套视图存在重复的列表行渲染与键盘事件代码。

**影响用户**：所有通过菜单栏图标点击浏览历史剪贴项的用户，尤其是开发者（复用代码片段）、文案工作者（复用文本模板）、客服（复用回复话术），以及需要频繁切换剪贴内容的所有用户。

**不解决会怎样**：菜单栏入口与快捷键入口体验割裂，用户在菜单栏场景仍需走「弹窗 → 切换应用 → 手动粘贴」的老路径，无法兑现「快速复用」的承诺；同时双套视图代码持续维护成本高，后续迭代容易遗漏某一入口。

## 3. Goals（目标）

### 3.1 用户目标

- 用户点击菜单栏图标弹出菜单栏弹窗后，**默认高亮第一行**，可直接用键盘方向键浏览、回车粘贴、双击粘贴、Esc 关闭。
- 双击或回车粘贴时，**与 F1.9 快捷粘贴面板完全一致的粘贴流程**：有辅助功能权限时自动粘贴到前台应用；无权限时写入剪贴板并显示浮层提示。
- 菜单栏弹窗底部新增「查看全部/配置/退出」三按钮，用户无需关闭弹窗即可打开主窗口、打开设置或退出。
- 快捷键入口的所有交互行为与 F1.9 完全一致（回归保护，无任何退化）。

### 3.2 业务目标

- 把菜单栏弹窗从「仅展示」升级为「完整剪贴复用入口」，与快捷键入口对齐。
- 通过视图层合并消除重复代码，使列表渲染、键盘交互、选中态逻辑只在一处实现，降低后续迭代成本。
- 沿用 F1.9 已建立的粘贴协调器、系统粘贴权限检查器、剪贴板写入器、粘贴浮层控制器等基础设施，不引入新的权限申请流程，不修改持久化逻辑。
- 保持 App Store 合规：主方案在沙盒内实现无权限降级方案；有权限方案使用公开 API + 标准 TCC 权限流程，合规风险在设计文档风险章节独立标注。

### 3.3 成功标准

- 菜单栏弹窗打开后默认高亮第一行，列表行支持双击粘贴、回车粘贴、方向键导航、Esc 关闭。
- 双击或回车触发粘贴流程：有辅助功能权限时自动粘贴到前台应用；无权限时写入剪贴板并显示浮层提示。
- 菜单栏弹窗底部显示「查看全部/配置/退出」三按钮，分别打开主窗口、打开设置、关闭弹窗。
- 快捷键入口的所有行为与 F1.9 完全一致（F1.9 已有自动化测试用例全部通过）。
- 菜单栏弹窗视图与快捷粘贴面板视图合并为同一视图，由状态栏图标控制器（菜单栏弹窗场景）和快捷键面板控制器（快捷键场景）分别包装。
- 底部工具栏在菜单栏弹窗场景显示三按钮，在快捷键场景隐藏。
- 面板关闭协议被状态栏图标控制器实现，关闭菜单栏弹窗与关闭快捷键面板使用统一接口。
- 状态栏图标控制器注入的剪贴项列表与剪贴板存储同步。
- 14 条 AC 全部通过（自动化测试 + 手动验收）。

## 4. Scope（范围）

### 4.1 必须做

- 视图层合并：菜单栏弹窗视图与快捷粘贴面板视图合并为统一粘贴面板视图，由状态栏图标控制器（菜单栏弹窗场景）和快捷键面板控制器（快捷键场景）分别包装。
- 底部工具栏条件渲染：菜单栏弹窗场景显示「查看全部/配置/退出」三按钮，快捷键场景隐藏底部工具栏。
- 列表行视图绑定单击与双击回调，接入粘贴协调器处理粘贴流程。
- 键盘事件监听：回车粘贴、上下方向键移动选中、Esc 关闭。
- 选中态高亮：列表出现时默认高亮第一行，单选模式，方向键可移动选中。
- 面板关闭协议扩展：状态栏图标控制器实现该协议，关闭菜单栏弹窗使用与关闭快捷键面板相同的接口。
- 数据源统一：剪贴项列表由外部注入，状态栏图标控制器与快捷键面板控制器从同一剪贴板存储取数据。
- 底部三按钮：「查看全部」（关闭弹窗并打开主窗口）、「配置」（关闭弹窗并打开设置窗口）、「退出」（关闭弹窗）。
- F1.11 规格文档套件（4 篇）+ F1.9 已有文档同步更新（在测试用例表阶段标注）。

## 5. Functional Requirements（功能需求）

### FR-001：菜单栏弹窗打开后默认高亮第一行

**需求**：用户点击菜单栏图标弹出菜单栏弹窗后，列表第一行立即高亮选中。

**行为**：

- 菜单栏弹窗打开时，若列表非空，第一行立即高亮。
- 同一时刻最多一行高亮（单选模式）。
- 高亮状态有明确的视觉差异（背景色或边框）。
- 高亮行可通过键盘方向键上下移动。

### FR-002：列表行双击触发粘贴流程

**需求**：菜单栏弹窗的列表行支持双击触发粘贴流程（与 F1.9 快捷粘贴面板完全一致）。

**行为**：

- 双击文本类型行：进入粘贴流程（FR-010 有权限路径或 FR-011 无权限路径）。
- 双击图片类型行：显示提示「仅支持文本粘贴」，不进入粘贴流程。
- 双击文件路径类型行：显示提示「仅支持文本粘贴」，不进入粘贴流程。
- 双击后立即关闭菜单栏弹窗（仅在文本类型粘贴流程中关闭；非文本类型不关闭）。

### FR-003：回车键粘贴

**需求**：菜单栏弹窗中高亮选中某行后，按回车键触发粘贴流程（等同于双击）。

**行为**：

- 高亮选中行 + 按回车：触发与双击相同的粘贴流程（FR-010 或 FR-011）。
- 未高亮选中行 + 按回车：不触发任何操作。
- 高亮行为为图片或文件路径类型时：显示「仅支持文本粘贴」提示，不进入粘贴流程。

### FR-004：键盘方向键导航

**需求**：菜单栏弹窗支持键盘方向键上下移动高亮选中行。

**行为**：

- 上方向键：高亮行上移一行（若已在第一行则不动）。
- 下方向键：高亮行下移一行（若已在最后一行则不动）。
- 方向键导航不影响列表滚动（必要时自动滚动以保持高亮行可见）。
- 弹窗出现时默认高亮第一行（与 FR-001 一致）。

### FR-005：Esc 键关闭菜单栏弹窗

**需求**：按 Esc 键关闭菜单栏弹窗，不触发粘贴。

**行为**：

- 按 Esc 键：立即关闭菜单栏弹窗。
- 不写入剪贴板，不触发粘贴流程。

### FR-006：底部「查看全部」按钮

**需求**：菜单栏弹窗底部新增「查看全部」按钮，点击后关闭弹窗并打开主窗口。

**行为**：

- 菜单栏弹窗场景下，底部工具栏左侧显示「查看全部」按钮。
- 点击「查看全部」按钮：立即关闭菜单栏弹窗，并向应用主代理发送「打开主窗口」信号。
- 主窗口打开后获得键盘焦点，用户可继续在主窗口中搜索与处理。

### FR-007：底部「配置」按钮

**需求**：菜单栏弹窗底部新增「配置」按钮，点击后关闭弹窗并打开设置窗口。

**行为**：

- 菜单栏弹窗场景下，底部工具栏中间显示「配置」按钮。
- 点击「配置」按钮：立即关闭菜单栏弹窗，并向应用主代理发送「打开设置窗口」信号。
- 设置窗口打开后获得键盘焦点，用户可继续配置应用。
- 应用内需新增「打开设置窗口」信号（若已有则复用）。

### FR-008：底部「退出」按钮

**需求**：菜单栏弹窗底部新增「退出」按钮，点击后关闭弹窗。

**行为**：

- 菜单栏弹窗场景下，底部工具栏右侧显示「退出」按钮。
- 点击「退出」按钮：立即关闭菜单栏弹窗。
- 不触发任何粘贴流程，不打开其他窗口。

### FR-009：图片/文件路径类型双击提示

**需求**：菜单栏弹窗中双击图片类型或文件路径类型行时，显示提示「仅支持文本粘贴」，不进入粘贴流程。

**行为**：

- 双击图片类型行：显示提示「仅支持文本粘贴」，不写入剪贴板，不关闭弹窗。
- 双击文件路径类型行：显示提示「仅支持文本粘贴」，不写入剪贴板，不关闭弹窗。
- 提示以非阻塞方式显示（如行内提示或浮层提示），用户可继续操作其他行。

### FR-010：有辅助功能权限时自动粘贴

**需求**：当应用已获得辅助功能权限时，双击或回车触发文本类型行的粘贴流程，自动粘贴到前台应用。

**行为**：

- 运行时检测辅助功能权限状态（不缓存上一次结果，不弹 TCC 提示对话框）。
- 有权限时：写入剪贴板 → 关闭菜单栏弹窗 → 模拟系统粘贴按键到前台应用。
- 模拟粘贴按键后，前台应用光标位置插入剪贴板文本内容。
- 粘贴完成后无浮层提示（用户感知是「双击即粘贴」，无中间步骤）。

### FR-011：无辅助功能权限时降级粘贴流程

**需求**：当应用未获得辅助功能权限时，双击或回车触发文本类型行的降级粘贴流程。

**行为**：

- 运行时检测辅助功能权限状态（不缓存，不弹 TCC 提示）。
- 无权限时：写入剪贴板 → 关闭菜单栏弹窗 → 显示浮层提示「已复制，按 Cmd+V 粘贴」。
- 浮层提示显示位置：屏幕中央或上次关闭位置。
- 浮层提示消失条件（任一满足即消失）：监听到剪贴板被消费、超时兜底消失（沿用 F1.9 已有的超时配置项）。
- 浮层提示不抢夺前台应用焦点。

### FR-012：快捷键入口行为与 F1.9 完全一致（回归保护）

**需求**：F1.11 完成后，快捷键入口的所有交互行为与 F1.9 完全一致，无任何退化。

**行为**：

- 快捷键触发呼出快捷粘贴面板的行为不变（沿用 F1.9 已有逻辑）。
- 快捷粘贴面板的列表行双击粘贴、回车粘贴、方向键导航、Esc 关闭、失焦关闭、粘贴后关闭、无权限降级浮层、超时配置等所有 F1.9 已有行为保持完全一致。
- F1.9 已有的自动化测试用例全部通过（无任何用例因 F1.11 改动而失败）。
- F1.9 已有的辅助功能标识符保持不变（不重命名）。

### FR-013：面板关闭协议扩展与状态栏图标控制器实现

**需求**：扩展已有的面板关闭协议，使状态栏图标控制器实现该协议，关闭菜单栏弹窗与关闭快捷键面板使用统一接口。

**行为**：

- 面板关闭协议定义「关闭当前面板」的统一接口（接口签名属于设计文档范围，本需求仅约束行为）。
- 快捷键面板控制器继续实现该协议（F1.9 已实现）。
- 状态栏图标控制器新增实现该协议：调用接口后关闭菜单栏弹窗。
- 粘贴协调器在粘贴流程中调用面板关闭协议接口时，菜单栏弹窗与快捷键面板均能正确关闭。

### FR-014：数据源统一与外部注入

**需求**：菜单栏弹窗与快捷粘贴面板的剪贴项列表由外部注入，两个控制器从同一剪贴板存储取数据。

**行为**：

- 菜单栏弹窗视图与快捷粘贴面板视图均通过外部注入接收剪贴项列表（视图本身不直接读取剪贴板存储）。
- 状态栏图标控制器在弹出菜单栏弹窗前，从剪贴板存储读取剪贴项列表并注入到视图。
- 快捷键面板控制器在弹出快捷粘贴面板前，从同一剪贴板存储读取剪贴项列表并注入到视图。
- 注入的剪贴项列表与剪贴板存储当前状态同步（无延迟、无缺失、无重复）。

## 6. Non-functional Requirements（非功能需求）

### NFR-001：响应性能

- 菜单栏图标点击到弹窗出现：≤ 200ms（沿用 F1.9 基线，用户感知「瞬间出现」）。
- 双击/回车触发粘贴到剪贴板写入完成：≤ 100ms。
- 有权限路径：模拟粘贴按键到前台应用插入文本：≤ 300ms（受前台应用响应速度影响，本指标仅约束 ClipMind 侧）。
- 列表行单击高亮、方向键导航：≤ 16ms（60FPS，无肉眼可感延迟）。
- 默认高亮第一行：弹窗出现的同时即生效，无可见延迟。

### NFR-002：稳定性

- 菜单栏弹窗的呼出/关闭/粘贴流程在 100 次连续操作中无崩溃、无内存泄漏（内存增长 < 5MB）。
- Esc 关闭、底部三按钮关闭、粘贴后关闭、失焦关闭（如启用）四种关闭路径互不冲突，不出现「关不掉」或「重复关闭」。
- 辅助功能权限检测在权限被授予/撤销/重新授予的循环中状态正确，不出现「卡在某一路径」。
- 视图层合并后，菜单栏弹窗场景与快捷键场景的行为保持一致，不出现「某场景有 bug 另一场景没有」的不对称问题。

### NFR-003：安全性

- 不在日志中输出剪贴板原文、密码、Token、验证码等敏感信息。
- 模拟粘贴按键仅发送系统标准粘贴按键事件，不发送任意按键序列。
- 浮层提示不显示剪贴板原文，仅显示「已复制，按 Cmd+V 粘贴」通用文案。
- 写入剪贴板的内容不绕过现有敏感识别与应用黑名单（若内容来自敏感来源，按现有隐私保护流程处理）。

### NFR-004：兼容性

- 兼容 macOS 13.0+（与项目主设计规范一致）。
- 兼容 Apple Silicon（arm64）与 Intel（x86_64）。
- 兼容现有菜单栏图标点击行为（不破坏 toggle 弹窗行为）。
- 兼容 F1.9 快捷键入口的所有已有行为（回归保护）。
- 兼容 F1.9 已有的辅助功能标识符（不重命名，保持自动化测试用例向后兼容）。
- 兼容现有「打开主窗口」信号（若已有则复用）。
- 老用户升级无感知迁移：菜单栏图标点击行为从「仅展示」升级为「完整交互」，无需重新配置。

### NFR-005：可访问性

- 菜单栏弹窗的所有交互元素支持 VoiceOver 朗读。
- 键盘导航完整覆盖所有操作（不依赖鼠标）。
- 高亮选中的视觉差异对色盲用户可识别（不仅依赖颜色，辅以形状或边框）。
- 底部三按钮支持键盘 Tab 焦点切换与回车激活。

### NFR-006：合规性（App Store）

- 主方案保持 App Store 合规：启用 App Sandbox、仅申请最小必要 entitlement、不使用私有 API。
- 无权限降级方案（FR-011）纯沙盒内实现，完全合规。
- 有权限方案（FR-010）使用公开 API + 标准 TCC 权限流程，合规风险独立标注（详见设计文档风险章节）。
- 若 App Store 审核拒绝有权限方案，则该方案暂存到开发验证 Scheme，主方案仅保留无权限降级方案。

### NFR-007：可维护性

- 视图层合并后，列表渲染、键盘事件、选中态逻辑只在一处实现。
- 后续修改列表交互（如新增多选、智能排序）只需改一处，菜单栏弹窗与快捷粘贴面板同步生效。
- 模块依赖方向保持：UI 层 → 业务模块 → 数据模型层，不引入反向依赖。

## 7. Constraints（约束）

### 7.1 业务约束

- **不改 F1.9 快捷键触发逻辑**：快捷键从「唤起主窗口」改为「呼出快捷粘贴面板」的逻辑保持不变，F1.11 不修改。
- **不改 F1.9 已有的辅助功能标识符**：保持向后兼容，避免 F1.9 已有的自动化测试用例失败。
- **不引入新权限申请流程**：辅助功能权限的检测与申请沿用 F1.9 已有逻辑（运行时检测，不弹 TCC 提示）。
- **不改剪贴板存储的持久化逻辑**：剪贴项列表的读取、写入、加密、清理等逻辑保持不变。
- **不改动主窗口功能**：主窗口内的搜索、详情、处理、设置功能不变，主窗口入口仍为菜单栏点击或「查看全部」按钮。
- **不删除菜单栏 toggle 行为**：菜单栏图标点击仍弹出菜单栏弹窗（与快捷键面板是两个独立入口）。

### 7.2 兼容约束

- **macOS 13.0+**：与项目主设计规范一致。
- **老用户无感知迁移**：菜单栏图标点击行为升级，无需用户重新配置。
- **F1.9 测试用例回归**：F1.9 已有的所有自动化测试用例必须通过。

### 7.3 合规约束

- **App Store 主方案合规**：所有面向发布的代码必须满足 App Store Review Guidelines 与 macOS 沙盒、隐私、权限约束。
- **辅助功能权限依赖标注**：有权限方案（FR-010）依赖辅助功能权限，需在设计文档风险章节标注「合规待定」状态。

## 8. Acceptance Criteria（验收标准）

> **格式约定**：每条 AC 用 Given/When/Then 描述，验证方式必须包含测试框架（XCTest/XCUITest/手动）。
> **AC 编号体系**：AC-F1.11-1 ~ AC-F1.11-14（独立于 F1 主规范与 F1.9 的 AC）。

### AC-F1.11-1：菜单栏弹窗打开后默认高亮第一行

- **Given** 应用已完成首次启动引导，剪贴板存储中至少有 1 条剪贴项
- **When** 用户点击菜单栏图标弹出菜单栏弹窗
- **Then** 列表第一行立即高亮显示，其他行不高亮
- **验证方式**：XCUITest

### AC-F1.11-2：双击文本行触发粘贴流程

- **Given** 菜单栏弹窗已打开，列表第一行是文本类型且已高亮
- **When** 用户双击第一行
- **Then** 该行文本被写入剪贴板 → 菜单栏弹窗关闭 → 有辅助功能权限时模拟粘贴按键到前台应用；无权限时显示浮层提示「已复制，按 Cmd+V 粘贴」
- **验证方式**：XCUITest + XCTest

### AC-F1.11-3：回车键触发选中行粘贴

- **Given** 菜单栏弹窗已打开，第一行文本类型已高亮选中
- **When** 用户按回车键
- **Then** 触发与双击相同的粘贴流程（写入剪贴板 + 关闭弹窗 + 有权限模拟粘贴/无权限显示浮层）
- **验证方式**：XCUITest

### AC-F1.11-4：方向键移动选中行

- **Given** 菜单栏弹窗已打开，列表有至少 3 行，第一行高亮
- **When** 用户按下方向键下
- **Then** 第二行高亮，第一行取消高亮
- **And When** 用户按下方向键上
- **Then** 第一行高亮，第二行取消高亮
- **验证方式**：XCUITest

### AC-F1.11-5：Esc 关闭菜单栏弹窗

- **Given** 菜单栏弹窗已打开
- **When** 用户按下 Esc 键
- **Then** 菜单栏弹窗立即关闭；剪贴板内容不变；不触发粘贴流程
- **验证方式**：XCUITest

### AC-F1.11-6：底部「查看全部」按钮关闭弹窗并打开主窗口

- **Given** 菜单栏弹窗已打开
- **When** 用户点击底部「查看全部」按钮
- **Then** 菜单栏弹窗关闭；主窗口出现并获得键盘焦点
- **验证方式**：XCUITest

### AC-F1.11-7：底部「配置」按钮关闭弹窗并打开设置窗口

- **Given** 菜单栏弹窗已打开
- **When** 用户点击底部「配置」按钮
- **Then** 菜单栏弹窗关闭；设置窗口出现并获得键盘焦点
- **验证方式**：XCUITest

### AC-F1.11-8：底部「退出」按钮关闭弹窗

- **Given** 菜单栏弹窗已打开
- **When** 用户点击底部「退出」按钮
- **Then** 菜单栏弹窗关闭；不打开其他窗口；不触发粘贴流程
- **验证方式**：XCUITest

### AC-F1.11-9：图片/文件路径类型双击显示提示

- **Given** 菜单栏弹窗已打开，列表中包含图片类型行或文件路径类型行
- **When** 用户双击图片类型行或文件路径类型行
- **Then** 显示提示「仅支持文本粘贴」；不写入剪贴板；不关闭弹窗；用户可继续操作其他行
- **验证方式**：XCUITest

### AC-F1.11-10：无辅助功能权限时双击显示粘贴浮层

- **Given** 应用未获得辅助功能权限，菜单栏弹窗已打开
- **When** 用户双击列表中某文本类型行
- **Then** 该行文本被写入剪贴板 → 菜单栏弹窗关闭 → 浮层提示「已复制，按 Cmd+V 粘贴」出现 → 监听剪贴板被消费后浮层消失，或超时兜底后浮层消失
- **验证方式**：XCTest + 手动

### AC-F1.11-11：快捷键入口行为与 F1.9 一致（回归保护）

- **Given** F1.11 已完成实现
- **When** 运行 F1.9 已有的所有自动化测试用例（快捷键呼出、双击粘贴、回车粘贴、方向键导航、Esc 关闭、失焦关闭、粘贴后关闭、无权限降级浮层、超时配置等）
- **Then** 所有 F1.9 已有用例全部通过；F1.9 已有的辅助功能标识符未发生重命名
- **验证方式**：XCUITest 回归

### AC-F1.11-12：面板关闭协议被状态栏图标控制器实现

- **Given** F1.11 已完成实现
- **When** 通过单元测试调用状态栏图标控制器的面板关闭协议接口
- **Then** 菜单栏弹窗被关闭（行为等同于用户按 Esc 关闭）；接口签名与快捷键面板控制器使用的接口一致
- **验证方式**：XCTest

### AC-F1.11-13：底部工具栏条件渲染

- **Given** F1.11 已完成实现
- **When** 通过单元测试在菜单栏弹窗场景与快捷键场景下检查统一粘贴面板视图的底部工具栏可见性
- **Then** 菜单栏弹窗场景下底部工具栏可见（显示「查看全部/配置/退出」三按钮）；快捷键场景下底部工具栏不可见
- **验证方式**：XCTest

### AC-F1.11-14：状态栏图标控制器注入的剪贴项与剪贴板存储同步

- **Given** 剪贴板存储中已有若干剪贴项，状态栏图标控制器尚未弹出菜单栏弹窗
- **When** 用户点击菜单栏图标弹出菜单栏弹窗
- **Then** 菜单栏弹窗列表显示的剪贴项与剪贴板存储当前状态完全一致（数量、顺序、内容一致）
- **验证方式**：XCTest

## 9. Out of Scope（明确不做）

### 9.1 不改 F1.9 快捷键触发逻辑

- F1.9 快捷键从「唤起主窗口」改为「呼出快捷粘贴面板」的逻辑保持不变。
- 不修改全局快捷键的注册、监听、配置逻辑。
- 不修改快捷键配置 UI。

### 9.2 不改 F1.9 已有的辅助功能标识符

- F1.9 已有的所有辅助功能标识符保持向后兼容（不重命名）。
- F1.9 已有的自动化测试用例不因标识符变化而失败。

### 9.3 不引入新权限申请流程

- 辅助功能权限的检测与申请沿用 F1.9 已有逻辑。
- 不弹 TCC 提示对话框（运行时静默检测）。
- 不引入新的权限申请 UI。

### 9.4 不改剪贴板存储的持久化逻辑

- 剪贴项的读取、写入、加密、清理、过期等逻辑保持不变。
- 不新增剪贴项字段（不增加「已粘贴次数」等统计字段）。
- 不修改现有剪贴项数据模型。

### 9.5 不改动主窗口功能

- 主窗口内的搜索、详情、处理、设置功能不变。
- 主窗口入口仍为菜单栏点击或「查看全部」按钮。
- 不调整主窗口布局、视觉、交互。

### 9.6 不实现图片/文件路径自动粘贴

- 图片类型双击仅显示「仅支持文本粘贴」提示，不写入剪贴板、不粘贴。
- 文件路径类型双击仅显示「仅支持文本粘贴」提示，不写入剪贴板、不粘贴。
- 后续迭代再考虑图片/文件路径的粘贴方案。

### 9.7 不实现多选批量粘贴

- 列表行仅支持单选（高亮选中最多一行）。
- 不支持 Shift+点击多选、Cmd+点击多选。
- 不支持「选中多行后一次性粘贴合并文本」。

### 9.8 不修改菜单栏图标 toggle 行为

- 菜单栏图标点击仍弹出菜单栏弹窗（与快捷键面板是两个独立入口）。
- 不删除菜单栏图标 toggle 行为，不合并菜单栏图标点击与快捷键触发。

### 9.9 不实现「配置」按钮打开特定设置页

- 「配置」按钮仅打开设置窗口（不指定打开哪个设置页）。
- 不实现「智能跳转到相关设置页」的功能。
- 设置窗口打开后由用户自行选择配置项。

| 辅助功能权限 | macOS 系统的辅助功能 TCC 权限，授予后应用可获取前台应用光标位置、模拟按键事件 |
| 辅助功能标识符 | 自动化测试用例用于定位 UI 元素的稳定标识，F1.9 已有的标识符保持不变 |
| 剪贴板消费 | 剪贴板内容被其他应用读取或覆盖（变化计数变化），作为浮层提示消失的条件之一 |
| 超时兜底 | 浮层提示显示的最大时长（沿用 F1.9 已有配置项，默认 5 秒），超时后强制消失 |

## 11. Decision Freedom（实现自由度）

### 11.1 允许的实现自由度

- **视图合并的命名**：合并后的统一粘贴面板视图的命名（如「统一粘贴面板视图」「合并粘贴视图」等）由设计阶段决定，本需求只约束行为。
- **底部工具栏的视觉风格**：底部工具栏的视觉风格（按钮排列、间距、图标、配色）由设计阶段决定，本需求只约束「三按钮存在且可点击」。
- **视图状态管理器的复用方式**：是否复用 F1.9 已有的视图状态管理器，或新建独立管理器，由设计阶段决定，只要满足「单一管理器支撑两个场景」的合并目标。
- **面板关闭协议的接口形态**：协议的方法签名、参数、返回值由设计阶段决定，本需求只约束「状态栏图标控制器实现该协议」与「关闭菜单栏弹窗使用与关闭快捷键面板相同的接口」。
- **键盘事件监听实现方式**：方向键/回车/Esc 的监听可通过声明式 UI 框架的按键事件修饰符、应用工具包的按键事件回调或其他公开 API 实现，只要满足「上下方向键移动高亮、回车粘贴、Esc 关闭」约束。
- **列表行视图复用方式**：可复用 F1.9 已有的列表行视图骨架并扩展，或新建独立视图，只要视觉与 F1.9 一致。
- **「打开设置窗口」信号的实现方式**：可通过应用内已有的信号机制（与「打开主窗口」信号同类型）实现，或新建独立机制，只要满足「点击配置按钮后关闭弹窗并打开设置窗口」约束。
- **剪贴项列表注入方式**：可通过构造器注入、属性注入或其他依赖注入方式实现，只要满足「视图不直接读取剪贴板存储」与「注入的列表与存储同步」约束。
- **底部工具栏的显隐控制方式**：可通过视图参数、环境值、条件渲染或其他机制控制显隐，只要满足「菜单栏弹窗场景显示、快捷键场景隐藏」约束。

### 11.2 禁止的实现方式

- **禁止使用私有 API**：所有实现必须使用公开 API，满足 App Store 合规。
- **禁止绕过沙盒**：所有实现必须在 App Sandbox 内完成，不通过外部进程、脚本或辅助工具绕过沙盒限制。
- **禁止缓存辅助功能权限状态**：每次触发粘贴流程时必须运行时检测权限状态，不缓存上一次结果（避免权限被撤销后仍走有权限路径）。
- **禁止弹 TCC 提示对话框**：菜单栏弹窗触发粘贴流程时不弹 TCC 提示（避免打断用户工作流），仅查询当前权限状态。
- **禁止在日志中输出剪贴板原文**：所有日志仅记录元数据（如「已写入剪贴板，长度 256」），不记录剪贴板原文。
- **禁止发送任意按键序列**：模拟粘贴按键仅发送系统标准粘贴按键，不发送其他按键。
- **禁止浮层提示显示剪贴板原文**：浮层提示仅显示「已复制，按 Cmd+V 粘贴」通用文案。
- **禁止修改主窗口功能**：主窗口内的搜索/详情/处理/设置功能不变。
- **禁止删除菜单栏图标 toggle 行为**：菜单栏图标点击仍弹出菜单栏弹窗，与快捷键面板是两个独立入口。
- **禁止重命名 F1.9 已有的辅助功能标识符**：保持向后兼容，避免 F1.9 自动化测试用例失败。
- **禁止修改 F1.9 快捷键触发逻辑**：F1.9 快捷键的注册、监听、配置逻辑保持不变。
- **禁止修改剪贴板存储的持久化逻辑**：剪贴项的读取、写入、加密、清理逻辑保持不变。
- **禁止使用固定 sleep 等待异步逻辑**：浮层提示的消失条件（消费/超时）必须使用明确的条件等待，不用固定 sleep 掩盖竞态。
- **禁止在两个场景分别维护列表交互逻辑**：列表渲染、键盘事件、选中态逻辑必须在统一粘贴面板视图中实现一次，不允许两个控制器各写一份。

## 12. Future Considerations（未来扩展）

### 12.1 图片/文件路径自动粘贴

- 当前仅支持文本类型自动粘贴，未来可扩展图片类型（写入剪贴板图片 + 模拟粘贴）与文件路径类型（写入剪贴板文件 URL + 模拟粘贴）。
- 需考虑前台应用是否支持图片/文件粘贴（如备忘录支持图片、终端不支持图片）。

### 12.2 多选批量粘贴

- 当前仅支持单选，未来可扩展 Shift+点击多选、Cmd+点击多选。
- 多选后可「选中多行后一次性粘贴合并文本」（按时间顺序或选中顺序合并）。

### 12.3 智能排序

- 当前列表按时间倒序，未来可扩展智能排序（最近粘贴优先、最常粘贴优先、当前前台应用相关优先）。
- 需考虑性能：智能排序需在弹窗出现前完成，避免延迟。

### 12.4 自定义面板尺寸

- 当前面板尺寸固定，未来可扩展用户自定义尺寸（拖拽调整、设置项配置）。
- 需考虑记忆用户上次尺寸偏好。

### 12.5 二次快捷键 toggle 关闭

- 当前快捷键是单向触发，未来可扩展「再按一次关闭面板」。
- 需解决快捷键在面板已打开时被前台应用拦截的状态一致性问题。

### 12.6 粘贴历史统计

- 当前不记录粘贴次数，未来可扩展「已粘贴次数」统计字段，用于排序（最常粘贴优先）。
- 需考虑隐私：粘贴次数是元数据，不涉及剪贴板原文，可安全存储。

### 12.7 底部工具栏扩展

- 当前底部工具栏仅有「查看全部/配置/退出」三按钮，未来可扩展更多便捷入口（如「清空历史」「导出」「反馈」）。
- 需考虑按钮数量过多时的视觉拥挤问题。

### 12.8 多显示器支持

- 当前菜单栏弹窗绑定在菜单栏图标位置，未来可扩展多显示器支持（弹窗出现在光标所在显示器）。
- 需考虑跨显示器的坐标转换。
