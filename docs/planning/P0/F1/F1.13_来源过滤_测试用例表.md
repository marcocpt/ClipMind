- **性能用例**：Checkbox 切换后列表更新 ≤ 50ms、来源应用列表提取 ≤ 50ms、筛选按钮到浮层弹出 ≤ 100ms
- **合规性用例**：App Store 合规性审查全部通过（代码审查）
- **可维护性用例**：过滤逻辑复用与模块依赖方向审查通过（代码审查）

### 5.3 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 来源过滤器 API 从单选改为集合影响现有调用方 | 编译错误或运行时行为不一致 | Phase 0 实现时集中修改所有调用方，编译即可发现遗漏 |
| 大量剪贴项（>1000）时过滤性能下降 | 列表更新延迟超标 | 内存中集合包含判断复杂度 O(n)，1000 条以内 ≤ 50ms；后续可优化为预计算索引 |
| Checkbox 联动逻辑在两个模块中重复实现导致不一致 | 主窗口与弹窗联动行为不同 | 逻辑简单且固定，测试用例覆盖两个场景的联动行为 |
| 弹窗浮层定位在极端屏幕尺寸下异常 | 浮层位置不正确 | 使用声明式 UI 框架的浮层定位机制自动处理 |
| 搜索服务适配多选集合的具体方式不确定 | 搜索结果过滤逻辑与预期不符 | 设计文档 10.3 待确认问题已标注，Phase 0 实现时决策 |
