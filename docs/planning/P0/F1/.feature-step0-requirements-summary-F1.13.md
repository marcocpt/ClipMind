# F1.13 来源过滤 — 需求摘要

> 最后更新：2026-07-27 | 版本：v1.0

## 1. 用户问题与业务目标

用户无法按来源 App 过滤剪贴板内容。当前主窗口的 SourceFilter 只过滤搜索结果，历史列表不受影响；菜单栏弹窗和快捷键面板完全没有来源过滤功能。本特性让用户能在所有视图中按来源 App 多选过滤，快速定位特定 App 的剪贴内容。

## 2. 成功标准

主窗口和弹窗都能按来源 App 多选过滤，历史列表和搜索结果均受过滤影响，过滤状态直观易用。

## 3. 范围边界

**必须**：
- 主窗口 SourceFilter 从单选改为多选 Checkbox
- 主窗口 HistoryListView 历史列表受来源过滤影响
- 主窗口 SearchResultsView 搜索结果受来源过滤影响（已有，需适配多选）
- 菜单栏弹窗加来源筛选按钮 + App 多选浮层
- 快捷键面板加来源筛选按钮 + App 多选浮层
- 来源 App 列表从当前数据动态提取
- 过滤后无结果时显示空状态提示
- 主窗口与弹窗过滤状态独立
- 过滤状态不持久化（每次打开默认全部）

**明确不做**：
- DetailPanel（详细面板）不加来源过滤（只显示单个剪贴项）
- 不获取 App 图标（仅使用 App 名称文字）
- 不持久化过滤选择
- 不改变 ClipItem 模型

## 4. 用户流程

### 主窗口

1. 入口：主窗口搜索栏旁的来源过滤下拉菜单
2. 点击下拉展开 Checkbox 列表（含「全部」和各 App 名称）
3. 勾选/取消勾选 App
4. 历史列表和搜索结果实时过滤
5. 无匹配结果时显示空状态提示

### 弹窗（菜单栏/快捷键）

1. 入口：搜索栏旁的筛选按钮（漏斗图标）
2. 点击筛选按钮弹出 App 多选浮层
3. 勾选/取消勾选 App
4. 列表实时过滤
5. 点击浮层外区域关闭浮层

## 5. 数据与接口

- 修改 `SourceFilter`：`Binding<String?>` → `Binding<Set<String>>`（多选集合）
- `HistoryListView` 新增来源过滤参数
- `UnifiedPastePanelView` 新增来源过滤状态和筛选按钮
- `UnifiedPastePanelViewModel` 新增过滤逻辑
- `ClipStore` 或数据层提供 `availableSourceApps` 动态提取方法
- 来源 App 列表从 `ClipItem.sourceAppName` 提取去重排序

## 6. 兼容与迁移

- `SourceFilter` API 变更：`selectedApp: Binding<String?>` → `selectedApps: Binding<Set<String>>`
- 所有使用 SourceFilter 的调用方需适配
- `HistoryListView` 需新增 `sourceFilter` 参数
- 不改变 ClipItem 持久化格式
- 不影响旧行为：不选任何过滤等价于"全部"

| AC-4 | 弹窗搜索栏旁有筛选按钮，点击弹出 App 多选浮层 | XCUITest |

## 8. 阶段拆分

| Phase | 目标 | 可交付结果 |
|-------|------|-----------|
| Phase 0 | SourceFilter 多选改造 + 主窗口历史列表过滤 | SourceFilter 多选 Checkbox、主窗口历史列表和搜索结果均受过滤影响、动态 App 列表、空状态提示 |
| Phase 1 | 弹窗筛选按钮 + 浮层 + 过滤 | 弹窗筛选按钮、App 多选浮层、列表过滤、浮层交互（点击外部关闭）、状态独立 |
