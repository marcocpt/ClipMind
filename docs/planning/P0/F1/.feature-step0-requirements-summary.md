# F1.12 详细窗口内容可编辑 — 需求摘要

> 最后更新：2026-07-27 | 版本：v1.0

## 1. 用户问题与业务目标

用户在详细窗口中发现剪贴板内容有误或想修改时，无法直接编辑，必须重新复制。本功能让用户能在详细窗口中直接编辑内容，提升内容复用效率。

## 2. 成功标准

用户点击详细窗口文本区域即可编辑，编辑内容实时自动保存到数据库，Cmd+Z 可撤销，保存后同步到系统剪贴板。

## 3. 范围边界

**必须**：
- 文本类型（.text）可编辑
- 文件路径类型（.filePath）可编辑
- 点击即编辑（光标出现可打字）
- 实时自动保存到数据库
- Cmd+Z 撤销编辑
- 保存后内容同步到系统剪贴板

**明确不做**：
- 图片类型不支持编辑（显示提示）
- 不添加富文本编辑（仅纯文本）
- 不改变 AI 处理功能行为

## 4. 用户流程

1. 入口：点击详细窗口文本区域
2. 进入编辑模式（光标出现，TextEditor 可编辑）
3. 编辑内容（打字、删除、粘贴等）
4. 实时自动保存（每次内容变更保存到数据库）
5. Cmd+Z 撤销编辑
6. 切换到其他剪贴条目时自动保存当前编辑
7. 保存后内容同步到系统剪贴板

## 5. 数据与接口

- 修改 `ClipContent` 的 `.text` 和 `.filePath` 值
- 通过 `onUpdateClip` 回调更新数据库
- 编辑保存后写入 `NSPasteboard.general`
- UI 层：`DetailPanel` 中 `Text` 视图替换为可编辑的 `TextEditor`

## 6. 兼容与迁移

- 不影响旧行为：不可编辑时仍显示内容预览
- 新增编辑状态不影响 AI 处理功能
- 不改变 `ClipItem` 的持久化格式

## 8. 阶段拆分

| Phase | 目标 | 可交付结果 |
|-------|------|-----------|
| Phase 0 | 文本内容编辑 + 自动保存 + 撤销 | 文本类型可点击编辑、实时保存、Cmd+Z 撤销 |
| Phase 1 | 文件路径编辑 + 图片提示 + 剪贴板同步 | 文件路径可编辑、图片显示提示、保存后同步剪贴板 |
