# F1.11 菜单栏弹窗双击粘贴 — 步骤 0 需求摘要

> 本文件由 dd-feature-development-workflow 步骤 0.4 写入，供步骤 2 调用 dd-writing-specs 时复用，跳过重复 grill。
> 清理责任归本工作流步骤 9.1，dd-writing-specs 不清理此文件。

## 1. 用户问题和业务目标

**问题**：菜单栏图标点击弹出的 NSPopover（PopoverView）当前不支持双击粘贴/键盘交互，用户必须打开主窗口或使用快捷键才能粘贴，两个入口交互割裂。

**目标**：让菜单栏 popover 与 F1.9 快速粘贴面板交互完全对齐——双击/回车粘贴、方向键导航、选中态、Esc 关闭、默认高亮第一行；新增底部工具栏「查看全部/配置/退出」三按钮；视图层合并减少代码重复。

## 2. 成功标准

- 菜单栏 popover 文本行双击 → 写剪贴板 + 关闭 popover + 有权限模拟粘贴/无权限显示浮层
- 回车粘贴、↑↓导航、Esc 关闭、默认高亮第一行全部生效
- 底部工具栏：查看全部（左，已有）/配置（中，新增，打开设置窗口）/退出（右，新增，关闭 popover）
- PopoverView 与 QuickPasteView 合并为同一 SwiftUI 视图，bottomBar 条件渲染
- PanelClosing 协议扩展，StatusItemController 实现该协议
- 复用 PasteCoordinator/SystemPastePermissionChecker/ClipboardWriter/PasteOverlayController
- 所有 AC 通过 XCTest + XCUITest

## 3. 范围边界

### 必须做

- 视图层合并：PopoverView + QuickPasteView → PastePanelView（命名待设计阶段定）
- bottomBar 条件渲染：popover 场景显示三按钮，快捷键场景隐藏
- ClipRowView 绑定 onDoubleClick/onSingleClick，接入 PasteCoordinator
- 键盘事件监听：回车/↑↓/Esc
- 选中态高亮 + 默认第一行
- PanelClosing 协议扩展，StatusItemController 实现（closePanel 调用 popover.performClose）
- StatusItemController 注入 clips 和 PasteCoordinator 回调
- 数据源统一：clips 由外部注入（StatusItemController 和 QuickPastePanelController 从同一 ClipStore 取）
- 底部三按钮：查看全部（打开主窗口+关 popover）、配置（打开设置+关 popover）、退出（关 popover）
- F1.11 规格文档套件（4 篇）+ F1.9 文档同步更新

### 明确不做

- 不改 F1.9 快捷键触发逻辑
- 不改 F1.9 已稳定 XCUITest 用例的 accessibilityIdentifier（保持向后兼容）
- 不引入新权限申请流程
- 不改 ClipStore 持久化逻辑

## 4. 用户流程

- **状态栏入口**：点击状态栏图标 → NSPopover 弹出 PastePanelView（含 bottomBar）→ 默认高亮第一行 → 双击/回车粘贴 → 关闭 popover + 写剪贴板 → 有权限模拟粘贴/无权限显示浮层
- **快捷键入口**：按快捷键 → NSPanel 弹出 PastePanelView（无 bottomBar）→ 交互同上
- **配置按钮**：点击 → 关闭 popover + 打开设置窗口
- **退出按钮**：点击 → 关闭 popover
- **查看全部按钮**：点击 → 关闭 popover + 打开主窗口
- **Esc**：关闭 popover/panel

## 5. 数据和接口

- QuickPasteViewModel → 可能重命名为 PastePanelViewModel，或保持原名复用

- Notification.Name.openSettings（如未有）

## 架构决策

**视图层合并**：PopoverView 与 QuickPasteView 合并为 PastePanelView，由 StatusItemController（NSPopover）和 QuickPastePanelController（NSPanel）分别包装。bottomBar 在 popover 场景显示「查看全部/配置/退出」、在快捷键场景隐藏。用户在步骤 0 需求拷问中连续三次未明确选择，基于其他选择（完整对齐、统一外部注入、复用 PasteCoordinator）推断为视图层合并，用户在 0.3 出口判定中确认接受。
