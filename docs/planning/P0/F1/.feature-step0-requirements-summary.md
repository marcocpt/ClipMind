# F1.14 用户自定义标签 — 需求摘要

> 最后更新：2026-07-28 | 版本：v1.1

## 1. 用户问题与业务目标

剪贴板条目仅有自动分类标签（CODE/LINK/ERROR 等 11 种），用户无法按自身工作场景（如"重要""待处理""项目A"）自由标记和组织条目，导致大量历史内容难以按个人维度筛选和复用。本功能让用户能为条目添加自定义标签，支持搜索、多选、创建和删除，并将自动分类标签与用户标签合并为统一的标签体系。

## 2. 成功标准

用户可在主窗口、菜单栏弹窗和快捷粘贴面板中点击条目的标签区域弹出选择菜单，在菜单中搜索/多选已有标签或创建新标签；标签支持名称 + 预设色板颜色；自动分类标签与用户标签合并显示，用户可按条目移除或恢复自动分类标签；主窗口支持按标签过滤条目列表。

## 3. 范围边界

### 必须

- 点击标签/"+"弹出选择菜单（主窗口、菜单栏弹窗和快捷粘贴面板的条目均可触发）
- 菜单内搜索过滤 + 创建入口
- 多选标签（勾选/取消即时生效）
- 创建标签：名称 + 预设色板颜色
- 从条目移除标签（无需确认）
- 自动分类标签可按条目移除和恢复；移除后不会因重新加载而自动恢复
- 每条目最多 5 个标签，自动分类标签计入上限
- 点击标签或"+"只打开标签选择菜单，不触发条目的选择或粘贴动作
- 主窗口按标签过滤条目，并与搜索及来源筛选组合
- 设置页仅允许全局删除用户自定义标签（需二次确认）
- 设置页仅允许全局重命名用户自定义标签（需确认）
- 自动分类标签在设置页只读，不允许全局删除或重命名

### 明确不做

- 标签分组/层级
- 标签描述字段
- 自定义颜色选择器（仅预设色板）
- 拖拽排序标签
- 标签导入导出
- AI 自动推荐标签
- 标签快捷键绑定

## 4. 用户流程

### 4.1 添加/管理标签

1. 入口 A：主窗口、菜单栏弹窗或快捷粘贴面板中的条目有标签 → 点击任意标签 → 弹出标签选择菜单
2. 入口 B：条目无标签 → 显示"+"按钮 → 点击弹出标签选择菜单
3. 菜单内：已勾选当前条目的标签，可搜索/多选/创建/移除
4. 搜索框输入 → 过滤已有标签列表
5. 搜索无匹配时底部显示"创建 xxx"入口
6. 创建：输入名称 + 选预设颜色 → 创建并自动勾选
7. 移除：在菜单中取消勾选 → 直接从条目移除（无需确认）

### 4.2 全局管理

1. 设置页 → 标签管理 → 查看所有标签列表
2. 用户自定义标签可重命名 → 需确认 → 影响所有关联条目
3. 用户自定义标签可删除 → 需二次确认 → 从所有条目移除并从标签库删除
4. 自动分类标签可见但只读，不提供全局重命名或删除操作

### 4.3 按标签过滤

1. 主窗口过滤栏 → 选择标签 → 列表仅显示含该标签的条目
2. 支持多标签过滤（交集），并与搜索及来源筛选使用 AND 组合

## 5. 数据与接口

- `ClipItem` 新增 `tags: [Tag]` 字段
- 新增 `Tag` 模型（id: UUID, name: String, color: TagColor, isAutoGenerated: Bool）
- 新增 `TagColor` 枚举（预设色板，复用 TypeTagColor 色系）
- 标签持久化：SQLite tags 表 + clip_tags 关联表
- 自动分类标签以稳定身份存储，保留现有用户可见名称与颜色
- UI 层：TypeTagView 合并为统一 TagView

## 6. 兼容与迁移

- 旧数据无 tags 字段 → 迁移：根据 contentType 自动生成对应 Tag 并关联
- TypeTagView 重构为 TagView（统一自动标签和用户标签的视觉样式）
- 现有搜索与来源过滤增加标签维度
- 标签名称、颜色和条目关联关系使用与剪贴项一致的加密持久化保护

## 8. 阶段拆分

| Phase | 目标 | 可交付结果 |
|-------|------|-----------|
| Phase 0 | 数据模型 + Tag 视图 + 弹出菜单 + 创建/选择/移除 | 条目可挂标签，弹出菜单可搜索/多选/创建 |
| Phase 1 | 标签过滤 + 自动分类标签合并 + 旧数据迁移 | 主窗口按标签过滤并可与现有筛选组合，TypeTagView 合并，迁移正确 |
| Phase 2 | 设置页标签管理（用户标签全局删除/重命名） | 设置页可管理用户自定义标签，自动分类标签只读 |
