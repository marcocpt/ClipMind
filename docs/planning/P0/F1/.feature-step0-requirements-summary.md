# F1.10 快捷键默认值修改 — 步骤 0 需求摘要

> 本文件由 dd-feature-development-workflow 步骤 0.4 写入，供步骤 2 调用 dd-writing-specs 时复用，跳过重复 grill。
> 清理责任归本工作流步骤 9.1，dd-writing-specs 不清理此文件。

## 1. 用户问题和业务目标

**问题**：当前默认快捷键 `cmd+shift+v` 与 Paste 等热门剪贴板工具冲突（市场调研报告已标注 "this will drive you insane"），新用户安装后被劫持，影响首启体验。

**目标**：将默认快捷键改为 `cmd+shift+space`，避开主流应用冲突，且 space 键易于单手操作和记忆。

## 2. 成功标准

- 新安装用户默认 `cmd+shift+space` 触发快速粘贴面板
- 老用户升级后自动迁移到新默认值
- `HotkeyFormatter` 支持录制/解析/显示 space 键
- 设置页"重置"按钮重置为新默认值
- 测试常量化，后续修改默认值时只改一处
- 所有 AC 通过 XCTest + 手动验收

## 3. 范围边界

### 必须做

- 扩展 `HotkeyFormatter` 支持 space 键（keyCode=49）
- 修改三处默认值（`AppSettings`、`GeneralSettingsView`、`HotkeyRecorder` 重置按钮）
- 老用户迁移逻辑（检测 `cmd+shift+v` 自动迁移）
- 抽取测试常量 `TestHotkeys`（default / legacyDefault / arbitrary），让后续默认值修改只改一处
- 测试调整：
  - 修改 1 处默认值断言（`ClipItemModelTests.swift:195`）
  - 保留 1 处 `cmd+shift+v` 解析器测试作为回归保护
  - 保留 5 处服务 fixture 测试不动（hotkey 值非断言目标，可改用 `TestHotkeys.arbitrary` 提升语义）
  - 新增 8 处针对 F1.10 行为的测试
- F1.10 规格文档套件（4 篇：需求/设计/视觉原型/测试用例表）
- F1 主设计规范、F1.9 测试用例表、视觉原型 同步更新

### 明确不做

- 不改快捷键配置 UI（保留现有 HotkeyRecorder）
- 不改 F1.9 触发行为（仍是呼出快速粘贴面板）
- 不引入新的快捷键功能

## 4. 用户流程

- **新用户**：首启 → `hotkey=cmd+shift+space` → 按键呼出面板
- **老用户（旧默认值）**：升级首启 → 检测 `hotkey=="cmd+shift+v"` → 自动迁移为 `cmd+shift+space`
- **老用户（自定义值）**：升级首启 → 检测非默认值 → 保留不变
- **退出条件**：迁移在 AppSettings 初始化时执行一次

## 5. 数据和接口

### 修改

- `HotkeyFormatter.keyName`/`keyCode` 增加 `49 ↔ "space"` 映射
- `HotkeyFormatter.display` 增加 `space → "Space"` 大写显示（保持与字母键一致的大写形式）
- `AppSettings.hotkey` 默认值改为 `cmd+shift+space`
- `GeneralSettingsView.@AppStorage("hotkey")` 默认值同步
- `HotkeyRecorder` 重置按钮默认值同步

### 新增

- `AppSettings.migrateLegacyHotkey()` 迁移方法 + 在 AppSettings 初始化时调用
- `ClipMindTests/TestSupport/TestHotkeys.swift` 测试常量枚举：
  ```swift
  enum TestHotkeys {
      static let `default` = "cmd+shift+space"        // 当前默认值
      static let legacyDefault = "cmd+shift+v"        // 历史默认值（回归保护）
      static let arbitrary = "ctrl+opt+a"             // 任意有效值（fixture 用）
  }
  ```

## 6. 兼容和迁移

| 场景 | 旧值 | 新值 |
|------|------|------|
| 新用户首启 | 无 | `cmd+shift+space` |
| 老用户升级（旧默认） | `cmd+shift+v` | `cmd+shift+space` |
| 老用户升级（自定义） | 用户值 | 保留不变 |

迁移规则：`AppSettings.init` 时调用 `migrateLegacyHotkey()`，仅当 `hotkey == "cmd+shift+v"` 时改为 `cmd+shift+space` 并持久化。
