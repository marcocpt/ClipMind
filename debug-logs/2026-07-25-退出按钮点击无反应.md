# Bug 修复调试日志：退出按钮点击无反应

**日期**：2026-07-25
**Bug 描述**：顶部菜单栏弹出窗口，点击「退出」按钮没反应
**Worktree**：feature/F1.11-popover-double-click-paste

## 问题描述

用户在菜单栏点击 ClipMind 图标弹出 popover 后，点击底部「退出」按钮没反应。

## 前置：步骤 0 获取的运行日志信息

无日志（两个 logs 目录不存在或为空）。基于代码静态分析定位问题。

## 红灯：测试用例

在 `ClipMindTests/UI/BottomToolbarViewTests.swift` 末尾追加两个测试：

```swift
func testViewModel_HasOnExitAppCallback_DefaultNil()
{
    let viewModel = UnifiedPastePanelViewModel(clips: [])
    XCTAssertNil(viewModel.onExitApp, "onExitApp 默认应为 nil，由控制器注入")

func testViewModel_OnExitAppCallback_CanBeSetAndInvoked()

    let viewModel = UnifiedPastePanelViewModel(clips: [])
```

**红灯验证**：
- 测试因 `value of type 'UnifiedPastePanelViewModel' has no member 'onExitApp'` 编译失败
- 失败原因正确，非拼写错误

## 根因调查

### 现象分析

- UI 测试环境下（NSPanel），三按钮 5/5 通过
- 真实生产环境下（NSPopover），「查看全部」/「配置」按钮工作（用户之前反馈过「设置按钮报错」，按钮被触发）
- 真实生产环境下，「退出」按钮「没反应」

### 数据流追踪

`BottomToolbarView.onExit` → `UnifiedPastePanelView.bottomToolbar` 的 `onExit` 闭包 → `viewModel.onEscPressed?()` → `StatusItemController.closePanel()` → `popover.performClose(nil)`

### 与用户期望对比

询问用户具体现象后确认：**用户期望「退出」按钮退出整个应用**，而当前实现仅关闭 popover。

### 设计文档查证

设计文档第 696-700 行明确：

```
- 应用退出由系统菜单栏的「退出 ClipMind」入口承担（macOS 标准行为），菜单栏弹窗的「退出」按钮不应重复承担此职责。
- 上游需求摘要明确「退出按钮点击后关闭 popover」（AC-F1.11-8），未提及退出应用。
- 「退出」按钮的语义是「退出弹窗」（关闭弹窗回到原工作流），而非「退出应用」。
- 代价：用户可能期望「退出」按钮退出应用，需在视觉或提示中明确语义。
```

设计文档已预见此代价，但当前实现未提供视觉提示明确语义，导致用户期望落空。

### 根本原因

**需求/期望差异**：设计文档将「退出」按钮定义为「退出弹窗」，但用户期望「退出整个应用」。这不是代码 bug，而是需求调整。

### 调整方向（用户确认）

修改「退出」按钮行为为 `NSApp.terminate(nil)`，退出整个应用。

## 绿灯：修复实施

### 修改文件

1. **`ClipMind/UI/MenuBar/UnifiedPastePanelViewModel.swift`**：添加 `onExitApp: (() -> Void)?` 字段
2. **`ClipMind/UI/MenuBar/UnifiedPastePanelView.swift`**：`bottomToolbar` 的 `onExit` 改为调用 `viewModel.onExitApp?()`
3. **`ClipMind/UI/MenuBar/StatusItemController.swift`**：`makeUnifiedPanelView` 注入 `viewModel.onExitApp = { NSApp.terminate(nil) }`
4. **`ClipMind/App/PopoverPreviewWindowFactory.swift`**：UITEST 模式下注入 `viewModel.onExitApp = { window?.close() }` 测试 stub（避免真的退出测试进程）

### 关键代码

```swift
// UnifiedPastePanelViewModel.swift
var onExitApp: (() -> Void)?

// UnifiedPastePanelView.swift bottomToolbar
onExit:
{
    viewModel.onExitApp?()
}

// StatusItemController.swift makeUnifiedPanelView
viewModel.onExitApp = {
    NSApp.terminate(nil)
}

// PopoverPreviewWindowFactory.swift show
viewModel.onExitApp = { [weak window] in
    window?.close()
}
```

## 总结

- **Bug 类型**：需求/期望差异（非代码 bug）
- **根因**：设计文档将「退出」按钮定义为「退出弹窗」，与用户期望「退出整个应用」不符
- **修复方案**：将「退出」按钮行为改为 `NSApp.terminate(nil)`，通过 viewModel.onExitApp 回调抽象便于测试
- **影响范围**：
  - 菜单栏弹窗场景（showsBottomBar=true）：onExit 行为变更
  - 快捷键面板场景（showsBottomBar=false）：不受影响（不渲染 bottomToolbar）
- **测试**：
  - 新增 2 条 XCTest（验证 onExitApp 字段）
  - 现有 test04/test05 在 UITEST 模式下行为不变（onExitApp 注入为 window.close()）
  - 注释更新反映新语义
